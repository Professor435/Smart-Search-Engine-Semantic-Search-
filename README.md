## 🎯 How It Works

1. **Query Analysis** — AI parses intent, entities, and context from natural language
2. **Vector Embedding** — Query converted to high-dimensional semantic vector
3. **Similarity Search** — Approximate nearest neighbor (ANN) search across vectors
4. **Smart Ranking** — Cross-encoder re-ranking with user behavior signals
